# Audio Genre Classifier

Upload a music clip to run Tanzin Jayang's CNN directly in your browser. Audio stays on your device.

The model achieved **81.73% recording-level test accuracy** and **0.8156 macro-F1** on 197 held-out GTZAN recordings. The split is recording-disjoint but not verified artist-disjoint. Scores are uncalibrated.

[Source and evaluation details](https://github.com/Tanzin2005/audio-genre-classifier)
